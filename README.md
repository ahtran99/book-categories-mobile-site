  <h1>Book Categories Mobile Website</h1>

  <h2>Description</h2>
  <p>
    A mobile-first web application that displays book categories and their related items.
    Users can select a category to view detailed book information, with data loaded dynamically from JSON
    and stored in Local Storage for persistent navigation across pages.
  </p>

  <h2>Features</h2>
  <ul>
    <li>Loads category and book data dynamically from a JSON file using jQuery AJAX</li>
    <li>Uses JavaScript classes and arrays to manage structured data</li>
    <li>Saves selected category data to Local Storage for use on a secondary page</li>
    <li>Displays book details based on the selected category</li>
    <li>Optional toggle to show or hide long descriptions</li>
    <li>Mobile-first and responsive layout</li>
  </ul>

  <h2>Tech Stack</h2>
  <ul>
    <li><strong>HTML5</strong> &ndash; Structure of the web pages</li>
    <li><strong>CSS3</strong> &ndash; Styling and responsive layout</li>
    <li><strong>JavaScript</strong> &ndash; Data handling, logic, and Local Storage</li>
    <li><strong>jQuery</strong> &ndash; AJAX requests and DOM manipulation</li>
    <li><strong>JSON</strong> &ndash; External data source for categories and books</li>
  </ul>

  <h2>What I Learned</h2>
  <ul>
    <li>Retrieving and processing JSON data using jQuery AJAX</li>
    <li>Using JavaScript classes to structure application data</li>
    <li>Persisting application state across pages with Local Storage</li>
    <li>Building multi-page navigation logic in a mobile web application</li>
    <li>Enhancing usability with conditional content display</li>
  </ul>
